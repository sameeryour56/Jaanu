Jaanu is a single-file personal AI assistant that runs in a browser.

## Files
- `index.html` - Open this file in Chrome to use Jaanu.
- `google_ai_studio_jarvis.html` - Same assistant, original file name.

## How to use
1. Open `index.html` in Chrome on your phone.
2. Open Settings (gear icon) in the assistant.
3. Paste your Google AI Studio API key there and save it.
4. Talk or type your command, for example: YouTube par music chalao, ek story sunao, WhatsApp kholo.

## Important
- Your API key is stored only in your browser's local storage. It is not stored in this repository.
- Never share your API key in chat or in a screenshot. If it leaks, delete it in Google AI Studio and create a new one.
- WhatsApp messages are only prefilled, you must tap Send. Calls open the dialer, you must tap the green call button.
